Source : [critères et tests du RGAA 4.1.2](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/), [méthodologie de test](https://accessibilite.numerique.gouv.fr/ressources/methodologie-de-test/), [références](https://accessibilite.numerique.gouv.fr/ressources/references/). Lien vers un critère : `https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#{n}` (`#3.2`).

## Classes
- **M, mesurable sur la maquette** : Seiri mesure, Hairyo juge et recommande.
- **P, à préparer dans la maquette** : rien à mesurer, mais le designer doit le prévoir (annotation pour le développement, élément à dessiner). Hairyo dit quoi préparer, écran par écran.
- **X, non évaluable sur maquette** : se joue dans le code (HTML, ARIA, CSS, scripts). Listé, jamais jugé : renvoyé à l'audit.
Un critère sans objet dans le fichier (pas de vidéo, pas de tableau, pas de CAPTCHA) passe en « Non applicable », avec sa raison.
